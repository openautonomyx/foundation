# OpenAutonomyX Agent Maturity Model

A ladder for assessing how governed and capable an agent (or an organization's agent practice) is. Maturity gates autonomy: higher autonomy requires higher maturity.

## Levels

1. **Ad-hoc** — agents built case-by-case; no identity, policy, or evidence. Observe/suggest only.
2. **Defined** — agents registered with identity, purpose, scoped tools, and policy bindings. Draft-for-review.
3. **Governed** — human approval, separation of duty, and evidence on consequential actions. Execute-with-approval.
4. **Measured** — continuous evaluation, observability, and drift detection feed trust. Execute-within-policy.
5. **Optimized** — feedback loops tune prompts, tools, routing, and cost; incidents drive improvement. Execute-with-post-review.
6. **Autonomous-governed** — certified-scope autonomy with closed-loop control, reconciliation, and proven rollback. Autonomous within certified scope.

## Dimensions Assessed

Identity & trust · authority scoping · policy & approval · evaluation & evidence · supply-chain integrity · observability · incident readiness · reliability (SLOs, rollback) · cost governance.

## Using the Model

- Assess each dimension independently; an agent's level is the **minimum** across required dimensions.
- Autonomy may not exceed the maturity level — promotion requires evidence and a decision record.
- Drift or incidents can demote an agent until remediated.

## Maturity Principle

Autonomy is earned by maturity and evidence, never assumed. Raise capability only as fast as you raise governance.
