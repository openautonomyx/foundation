# OpenAutonomyX Agent Provider Model

The OpenAutonomyX agent provider model defines how providers of models, agents, tools, and platforms are onboarded, governed, and held accountable.

## Purpose

Agents depend on third-party providers. Provider choice is a governance and security decision, not just a procurement one.

## Provider Types

- model providers (foundation and specialized models)
- agent providers (packaged agents)
- tool and API providers
- platform and framework providers
- data providers
- evaluation and safety providers
- infrastructure and runtime providers

## Provider Obligations

A governed provider should declare: identity, ownership, jurisdiction, security posture, privacy and data-handling terms, SLAs and reliability, model and data provenance, versioning and deprecation policy, compliance attestations, and incident commitments.

## Provider Governance

Providers are registered, risk-assessed, trust-scored, and reviewed on a cadence. External providers are treated as integrations with least-privilege access and continuous monitoring.

## Lock-In and Portability

Prefer providers that support open standards (MCP, A2A) and portable interfaces. Maintain exit and substitution paths for critical providers.

## Provider Principle

Trust in an agent is bounded by trust in its providers. The supply of capability must be as governed as its use.
