# Foundation Registry

The registry is the canonical place for governed foundation objects.

## Purpose

The registry turns foundation concepts into versioned, reviewable, traceable, and reusable assets.

Registered objects may include:

- identities
- entities
- capabilities
- policies
- controls
- risks
- decisions
- artifacts
- knowledge assets
- memories
- taxonomies
- trust assertions

## Registry Principles

Every registered object should define:

- identifier
- type
- owner
- lifecycle state
- version
- source
- provenance
- policy bindings
- trust state
- evidence
- review cadence

## Principle

A foundation concept becomes operational when it is registered, versioned, reviewed, and governed.
