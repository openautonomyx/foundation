# Auditability Policy

## Purpose

Auditability ensures that an independent reviewer can verify important actions, decisions, artifacts, policies, approvals, and outcomes.

## Policy Statement

Every consequential activity must generate sufficient evidence for later review, investigation, compliance, assurance, and learning.

## Required Audit Attributes

Audit records should capture:

- identity
- actor
- target
- action
- event
- timestamp
- policy context
- authorization context
- approval chain
- evidence
- result
- outcome
- exception where applicable

## Applies To

This policy applies to:

- access changes
- identity lifecycle changes
- trust changes
- policy changes
- production deployments
- data processing
- publication
- destructive actions
- financial authorization
- incident response
- exception handling
- agent execution above defined risk threshold

## Evidence Quality

Audit evidence should be:

- complete enough to support review
- tamper-evident where practical
- time-stamped
- attributable
- linked to related actions and events
- retained according to policy
- protected according to sensitivity

## Review

Audit records should be reviewable by authorized auditors, owners, approvers, and governance functions.

Access to audit records must itself be governed and logged.

## Principle

If an outcome cannot be independently reviewed, it cannot be responsibly governed.
